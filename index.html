faq

Questions, answered

Does the app record everything I type?

No. Trigger detection and snippet matching happen locally on your PC. Keystrokes aren't sent to an external server for snippet processing. You can even stop key detection manually while the app still runs. Full control!

Does it require an internet connection?

Core snippet detection and expansion work locally without cloud processing. Internet access may eventually be used for things like license validation, updates, or optional online features.

Does it work in Remote Desktop?

It's designed to work in remote or virtual desktop environments when your local Windows keyboard input is forwarded into the remote session. Compatibility can depend on the remote desktop software and how it handles input.

Can I use it in any Windows application?

It's designed to work broadly wherever normal simulated keyboard input is accepted. Some applications with special security or input restrictions may behave differently.

What happens when I reach 10 snippets?

Free users can keep up to 10 snippets active at a time. Pro removes that limit.

Are my snippets stored locally?

Yes, 100% of the time — snippets and trigger processing are intended to stay on your device, unless you explicitly enable an optional sync feature in the future.
